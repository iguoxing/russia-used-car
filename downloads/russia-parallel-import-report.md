## 01 核心结论

**1. 市场方向：平行进口没有退潮，2026 年反超官方渠道**

2026 年 1–9 月俄罗斯新车进口 30.1 万辆，其中「替代（平行）进口」15.35 万辆、占 51%，同比 +75%；官方渠道 14.75 万辆、同比 −3.4%；9 月替代进口占比冲到 66%。同期中国整车出口俄罗斯 75.26 万辆，重回第一大目的地，乘用车同比 +114.1%。

**2. 但玩法变了：从「低价冲量」变成「合规 + 售后 + 选品」**

2024-10 报废税上调 70–85%、2025-01 关税 20–38%、2025-07 OTTC 强制俄境内实验室认证、2026 年 СРОТ/СПОТ 预申报与 160 马力税费分水岭。高功率车型商业报废税约 80–90 万卢布，需求明显向 150 马力左右、税负可控的车型集中。

**3. 你手上的 5000 条明细不是平行进口名录，而是「官方直采基准盘」**

其中奇瑞俄罗斯子公司一家就 3,043 单 / $4,046 万，出口商多为主机厂，起运国 99.6% 中国直发；三份汇总名单里 TOP7 官方子公司占 2024 年 $81.16 亿的约 90%。真正的平行进口线索在 417 家长尾 + 经中亚/白俄转口的 385 家名单。

**4. 1084 条转口明细是特种车，不是乘用车**

原产国全部中国，96.8% 经白俄罗斯、99% 走铁路，但品类是 ATV / 雪地车 / 迷你摩托，单价中位数仅 $478/台。这条链路证明了「第三国转口 + 中国原产」的操作可行性，但货值结构与整车出口不同。

**5. 四维信号里，只有第 ④ 维是硬数据**

① 抱怨、② 搜索、③ RFQ 来自公开市场证据与关单行为代理，用于判断「卖什么、怎么卖」；④ 已花钱买来自关单，用于判断「找谁」。三者证据等级不同，不能互相替代，也不能把代理指标当成已成交需求。

**6. 100 家名单按「成交概率」而非采购金额排序**

综合分 = 采购实力 28 + 频次 14 + 新鲜度 14 + 平行属性 22 + 需求匹配 10 + 可切入性 12。因此 $942 万的 АВТОТРЕЙД КРАСНОДАР 排在 $8,906 万的 ЖЕФКО 之前——前者有转口经验、高单价豪车、体量适中更易切入。Excel 已附「金额排名」列，可随时按金额重排。

## 03 四维需求信号

### ① 有人抱怨　（证据强度 8.5/10）

**证据**

- 约 90% 平行进口车没有官方质保；配件等待周期可达 45 天以上，偏远地区更久（Izvestia / Fit Service / 俄汽车保险联合会）
- Zeekr 9X 平行进口车后电机减速器壳体开裂，维修报价约 75 万卢布且无原厂保修（Motoram.ru，2026-01）
- Lamark 防腐中心覆盖 17 个中国品牌 / 26 个地区；Sidorin Lab 对 200 万条社交舆情聚类，吐槽集中在锈蚀、备件周期、极寒冷启动（Известия，2025-08）
- 早期车机全中文，催生第三方刷机；底盘防腐、极寒适配、俄文说明书不足是高频抱怨

**商业含义**：抱怨不是坏消息，是「可定价的服务缺口」。车源同质化后，谁能把质保、备件、俄语化、防腐、认证单证打包，谁就能摆脱纯比价。

**对应动作**：报价单增加 4 个可选包：延保 / 常用易损件 / 俄语车机与本地地图 / 底盘防腐 + OTTC 与 СРОТ 单证代办。

### ② 有人在搜索　（证据强度 8.0/10）

**证据**

- Yandex Wordstat 2026-07：中国汽车整车月均搜索约 14 万次、汽配 4.5 万次、摩托/ATV 2.5 万次；热门车身为跨界车 / SUV / MPV
- Avito Auto 2026-07：中国新车需求同比 +27.9%（大盘 +9.4%），均价 380 万卢布；Hongqi 近 4 倍、Omoda / Jaecoo 2.3 倍、Geely +25%
- 车型级：Exeed RX 逾 5 倍、Omoda C5 3.5 倍、Jaecoo J7 2.1 倍、Hongqi HS3 +93%、Chery Tiggo 9 +54%、Haval H3 +52%
- 在中国生产的国际品牌（马自达、日产、宝马、奔驰）同样被高频搜索，与平行进口主力车型吻合

**商业含义**：把「需求增速榜」和「你关单里的品牌覆盖」叠起来看，缺口很清楚：Hongqi / Exeed / Zeekr / Li Auto / Lynk 需求旺但关单覆盖极低；CHERY / GAC / CHANGAN 覆盖已高，是红海。

**对应动作**：优先组货 Hongqi HS3、Omoda C5、Exeed RX、Jaecoo J7，以及中国产 Mazda CX-5 等 160 马力以下版本；配件按 3 月/10 月换胎季提前备货。

### ③ 有人在招标 / 发 RFQ / 挂需求　（证据强度 7.0/10）

**证据**

- B2B-Center：Южуралзолото 发布 Haval H5 5 台询价（2026-10-23 发布、10-29 截止）
- zakupki.gov.ru / Сбербанк-АСТ：Тында 市政 Haval Dargo 询价，预算 383 万卢布；МТС 公开征集 Haval M6 26 台
- FreeTender 上俄罗斯运输与物流类开放标的 2,456–3,058 个；Tektorg 亦有乘用车采购公告
- 关单侧代理证据：本批数据中多家进口商同时对接 3–4 家中国出口商，处于多源比价状态；部分以 ЦТ/ОТТ 报关行代理申报

**商业含义**：公开 RFQ 多为俄本土法人采购，中国供应商直接投标门槛高，但它验证了「中国品牌整车」已进入俄企业采购清单。更可操作的是关单里的比价行为：多供应商客户 = 明确的可替换窗口。

**对应动作**：建俄语 RFQ 周监控（Поставка автомобиля / Запрос цен / Haval / Chery / Geely），优先跟「对接≥3 家出口商」和「报关代理需穿透」的客户。

### ④ 已有人花钱买　（证据强度 10.0/10）

**证据**

- 5,000 条直采明细：$1.279 亿 / 10,387 台 / 115 家进口商，单价中位 $13,327/台
- 1,084 条转口明细：$951 万 / 21,548 台 / 21 家，白俄 96.8%，铁路 99%
- 三份汇总名单合计 809 家主体：2024 直采 $81.16 亿、2022-23 中亚转口 $11.16 亿、原产地中国转口 $951 万
- 归一化去重、剔除官方品牌方后得到 771 家合格池，筛出 100 家 S/A 级客户，历史进口额合计 $7.41 亿

**商业含义**：这是唯一可直接转成销售动作的硬证据：客户是谁、买了多少、多久买一次、什么价位、走哪条渠道。①②③ 决定话术，④ 决定名单。

**对应动作**：按 100 家名单做存续与联系方式核验 → 分层触达 → 小批量试单验证清关路径，再放量。

## 07 行动建议

**第 1 步｜先验真，再触达**

100 家客户做一轮存续核验：查 INN、官网、РБК/Контур.Фокус 工商信息，确认仍在进口；对「ЦТ/ОТТ ПО ПОРУЧЕНИЮ」类记录先穿透找实际货主。数据最新只到 2025-03，这一步不能省。

**第 2 步｜按税负倒推选品**

主力组货压在 150 马力左右、160 马力以下：Hongqi HS3 / Omoda C5 / Exeed RX / Jaecoo J7 / Haval H3，以及中国产 Mazda CX-5。高功率车型单独做报废税测算，不进常规报价。

**第 3 步｜把服务做成报价项**

把延保、易损件包、俄语车机与地图、底盘防腐、OTTC/СРОТ 单证代办做成 4 个可选包，直接对应 ① 的四类抱怨。这样报价不是比谁低，而是比谁让客户少踩坑。

**第 4 步｜建立 RFQ 周监控 + 小批量试单**

俄语关键词清单每周扫 B2B-Center / zakupki.gov.ru / Tektorg；同时对 S 级客户先走 1–2 台试单，把清关、认证、时效跑通，再谈年度框架。

## 08 数据局限、风险与来源

### 数据局限

- 数据时效：关单明细最新 2025-03、转口明细 2023-07，与 2026 年市场之间有时间差，客户经营状态必须重新核验。
- 样本截断：5000 条明细是「前 5000」导出，月度绝对量不代表市场走势；本报告的月度图只用于看单价与品牌结构。
- 主体识别：部分记录以报关行（ЦТ/ОТТ по поручению）名义申报，名称含 GERMANY / KAZAKHSTAN 等非公司字段，已在清洗中剔除或标注。
- 名称归一：俄文全称与缩写（ОБЩЕСТВО… / ООО）已合并，但个别截断名可能未完全匹配，Excel 保留「全量客户池」供复核。
- 外部来源：①②③ 中部分数字来自中文行业媒体转述的平台数据（Wordstat / Avito / Autostat），已在来源表标注，签约或备货前建议用一手平台复核。
- 政策变动：СРОТ/СПОТ 预申报、报废税逐年递增、认证周期与本地化积分仍在调整，报价须留税费浮动条款。
