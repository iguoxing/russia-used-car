# 俄罗斯汽车出口 · 分析与报价工具站

静态站点，部署于 GitHub Pages，自定义域名：`https://russia.used-car.cn`

一句话分工：**总览看板讲「找谁」→ 细分市场讲「卖什么」→ 报价计算器讲「怎么报价」→ 出口规则说明讲「怎么合规走完一单」**。

## 页面（单页 Tab 菜单工作台，4 个模块）

打开 `https://russia.used-car.cn/` 就是 **Tab 菜单页**：顶部 4 个菜单原地切换，不跳页、不丢计算器参数；第二行是当前模块的章节快捷导航，右侧可刷新 / 打印 / 独立打开本模块。URL 支持 `#/quotation`、`#/rules`、`#/segments` 直达并可分享；旧链接如 `index.html#clients` 会自动落到总览对应章节。

`index.html` 是 Tab 容器（懒加载 iframe + 高度自适应 + hash 路由），4 个子页带 `?embed=1` 时自动隐藏自身导航并把模块互链 / 锚点交给容器接管；不带参数时仍是可独立访问、打印、分享的完整页面。

## 全站计价币种（2026-11-13 晚升级）

- 计算器上方可选 `₽ 卢布 RUB` / `$ 美元 USD` / `¥ 人民币 CNY`，默认 RUB。**选一个币种，整个页面跟着变**：左侧 14 个金额输入框的数值与单位、独立的「车价币种」下拉（已锁为跟随全局）、4 个车型预设、运输方式预设、参数来源表 / 运费表 / 报废税表里的金额，以及右侧 KPI、成本阶梯、四种口径报价、情景敏感性、中俄文报价单、CSV 与打印。
- **锚定基准层**：`BASE[k]` 以各字段的锚定币种存值 —— 车价锚 CNY（中国采购）、运费与出口本地费锚 USD（国际物流）、俄方费用与法规阈值锚 RUB。输入框与结果都是它按当前汇率的投影。因此：
  - 切换币种**不改变任何结果**（RUB 模式默认示例 DDP 3,262,545 ₽ / CIF 报价 2,213,557 ₽，USD `$39,317.25` / `$26,675.79`，CNY `¥263,425.55` / `¥178,727.76`，来回切换差值为 0）；
  - 改汇率只影响外币锚定项（车价、运费、出口本地费），报废税基准 20,000 ₽ 等卢布法定值不受汇率带走；
  - 四组车型预设回归不变：326.3 万 / 572.4 万 / 390.8 万 / 290.6 万 ₽。
- 法规类 RUB 起征点与消费税阶梯单价在公式说明里保留卢布原文；表格与提示中的金额型数字带 `data-amt` 标记，会随币种换算。
- 参数保存改为存锚定值 + 币种（`ru_quote_params` 的 `__base` / `__ccy`），跨币种恢复不会串值；币种选择另存 `ru_quote_ccy`，可用 `quotation.html?ccy=USD` / `?ccy=CNY` 直达。
- 与 Tab 工作台兼容：在 `#/quotation` 内切换不改 hash、不跳页，切走再切回保留币种与参数。

## 四个新模块（2026-11-13 晚二）

| 模块 | 章节 | 做法与口径 |
|---|---|---|
| 利润与保本价 | 02 | 左侧 E 组新增「目标成交价 / 佣金率 / 单台销售费用」。净利 = 成交价 − 成交价×佣金率 − 销售费用 − 净成本；净成本 = 该术语下我方承担成本 − 13% 出口退税。保本价 = (净成本+销售费) ÷ (1−佣金率)；达标最低价 = (净成本+销售费) ÷ (1−佣金率−目标净利率)，分母 ≤0 时显示 0（不可达）。**这三个字段不进入对客报价单与成本明细 CSV**，只有内部方案对比 CSV 含净利 |
| 多方案报价对比 | 03 | 「把当前参数存为方案」最多 6 套（`ru_quote_plans`）。快照存锚定金额 + 全部参数 + 当时汇率 + 币种 + 关键结果（一律以 RUB 存），对比表统一按当前币种与汇率折算；点「载入」还原参数、汇率与币种。可导出对比 CSV |
| 口岸与运费表 | 06 | `rules_data.py` 的 `ROUTES` 7 条线路：满洲里 / 阿拉山口班列、绥芬河与满洲里 TIR、圣彼得堡滚装、海铁联运、40HQ 整箱。点「应用」把运费（USD 锚）、俄境内段（RUB 锚）、运输方式预设一次性写入左侧并重算。运价是公开资料参考中值，不是货代报价 |
| 车型参数库 | 07 | `rules_data.py` 的 `VEHICLES` 10 款：Jetour T2 1.5T/2.0T、瑞虎 7、星越 L 218/272hp、宋 PLUS DM-i、元 PLUS、Jolion、Tank 300、二手车示例。点「带入」写入车价（CNY 锚）、排量、功率、动力、车龄、车型描述与参考 HS，报废税系数自动重查。**价格为国内指导价占位，必须按实际采购发票价覆盖**；混动/纯电功率口径与 HS 子目须由报关行核定 |

## 报价计算器口径（重要）

- **汇率**：USD/RUB 82.98（俄央行 2026-11-13 官方）、CNY/USD 6.70（由俄央行交叉价推算示例，请填实际结汇价）。
- **税费**：关税 20%（15–25% 与 20–38% 两种口径并存）、增值税 22%（425-ФЗ 2026-01-01 起；部分资料仍写 20%）、报废税 = 20,000 ₽ × 系数（按排量 / 车龄 / 主体查表，个人优惠 0.17 / 0.26 需 ≤3 年 + ≤3.0L + ≤160hp）、消费税按马力阶梯、清关费按 2026 第 1638 号决议 8 档。
- **公式**：FOB = 车价 + 出口本地费；CIF = FOB + 运费 + 保险；VAT = (完税价 + 关税 + 消费税) × 税率；报废税单列不计入 VAT 基数；报价 = 该术语累计成本 ÷ (1 − 毛利率)；我方毛利含 13% 出口退税。全部公式在 `quotation.html` 第 08 章与 Excel 模板中公开；净利、保本价与达标最低价的公式同时列在该表第 11–13 行。
- **四处口径冲突**：增值税 20/22%、关税 15–25% vs 20–38%、EAEU 补差新规是否生效、报废税上调年份。计算器给默认值但**不替业务拍板**，正式报价须由俄方持牌报关行按 HS 子目书面核定；2027-01-01 报废税预计再涨 10–20%，长周期合同必须留调价条款。
- **这不是报关系统**：所有参数标注来源编号与 A/B/C 证据等级，见页面「参数来源」「数据来源」章节。

## 构建与复算（`tools/`）

```bash
python3 tools/build_calculator.py   # 生成 quotation.html（共享 CSS 从 analysis.html 取，因 index.html 已是 Tab 容器）
python3 tools/build_rules.py        # 生成 rules.html + downloads/russia-export-rules.md
python3 tools/build_xlsx.py         # 生成 downloads/russia-quotation-calculator.xlsx
python3 tools/patch_site.py         # 统一 analysis/segments/quotation/rules 的 nav、下载区与入口卡（前几步之后跑）
python3 tools/build_tabs.py         # 最后跑：生成 Tab 容器 index.html + analysis.html，给 4 个子页注入 embed 模式（幂等，可反复运行）
```

`build_tabs.py` 必须放在 `patch_site.py` 之后：后者会重写各页 `<nav>`，会覆盖嵌入模式下的导航改写。

`tools/rules_data.py` 是所有参数、来源、流程、单证、时间线、风险提示、`ROUTES`（口岸线路）与 `VEHICLES`（车型参数）的唯一数据源，改这里即可全局重算；`build_calculator.py` 会把两者序列化成页面里的 JS 常量供「应用 / 带入」按钮使用。规则 PDF 由 Chrome headless 打印 `rules.html` 生成（页面已内置 `@media print` 白底样式）。

本地自检（需先起 `python3 -m http.server`）：`index.html?selftest=1` 依次加载 4 个 Tab 并输出高度 / 标题 / 章节数；`index.html?selftest=2` 验证互链接管、章节跳转与计算器在 Tab 内可算。
